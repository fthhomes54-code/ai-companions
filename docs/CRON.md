# Companion outreaches cron

Proactive holiday / birthday messages are generated by an LLM (not templates) and inserted as assistant messages.

## Endpoint

`GET` or `POST` `/api/cron/outreaches`

Auth: `Authorization: Bearer $CRON_SECRET`  
(also accepts `?secret=` or `x-cron-secret` for debugging)

## Occasions

- New Year's Day / Eve
- Valentine's Day
- Women's Day, April Fools
- Mother's / Father's Day (US approximate fixed windows)
- Halloween, Thanksgiving (US approx)
- Christmas Eve / Christmas
- User **birthday** from `profiles.birthday`

Timezone: each user's `profiles.timezone` (default `America/Chicago`).

## Vercel Cron

`vercel.json` schedules:

```json
{ "path": "/api/cron/outreaches", "schedule": "0 */6 * * *" }
```

Every 6 hours. On Vercel Pro, set env `CRON_SECRET` and configure the same secret in project Cron settings so Vercel sends `Authorization: Bearer <CRON_SECRET>`.

Manual test:

```bash
curl -X POST "$NEXT_PUBLIC_SITE_URL/api/cron/outreaches" \
  -H "Authorization: Bearer $CRON_SECRET"
```

## Flow

1. Load all companions + owner profiles  
2. For today (and tomorrow window), match occasions  
3. Upsert `scheduled_outreaches`  
4. Generate personalized note via `generateOutreachMessage`  
5. Insert `messages` row + mark outreach `sent`
